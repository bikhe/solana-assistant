# solana-app

Оболочка на Tauri 2 + React + Tailwind CSS + Motion. Скриншоты в [docs/screenshots](docs/screenshots).

```sh
pnpm install
pnpm tauri dev    # окна + core из исходников (fake-режим по умолчанию, SOLANA_FAKE=0 для настоящего)
```

## Окна

Все окна объявлены в `src-tauri/tauri.conf.json`, фронтенд один: экран выбирается по метке окна.

| Окно       | Что делает                                                                                                                                                                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `overlay`  | Полоска вверху экрана: прозрачная, поверх всех окон, пропускает клики, пока нет карточки подтверждения. Живёт всё время работы приложения и отвечает за трей, горячую клавишу, автозапуск и первый запуск мастера (`views/useShellDuties.ts`). |
| `chat`     | Текстовый чат и история (голос и текст), хранится в `localStorage`.                                                                                                                                                                            |
| `settings` | Вкладки Общие, Голос, Модели, Ключи, Инструменты, MCP, Скиллы. Поля сохраняются сами.                                                                                                                                                          |
| `wizard`   | Мастер первого запуска: язык, микрофон, режим, ключи или модели, проверка «Эй, Солана».                                                                                                                                                        |

Закрытие чата, настроек и мастера прячет окно: приложение остаётся в трее. Второй запуск открывает чат.

У каждого окна своё подключение к core. Изменения настроек окна пересылают друг другу событием Tauri `settings-changed`.

## Только веб-часть в браузере

```sh
cd ../core && uv run solana-core --fake --port 8765 --token dev
cd ../app && pnpm dev   # http://localhost:1420/?port=8765&token=dev&view=chat&dev
```

`view` бывает `overlay`, `chat`, `settings`, `wizard`; `&dev` показывает переключатель окон в углу.

## i18n

Строки в `src/i18n/ru.ts` (источник ключей) и `src/i18n/en.ts`. `tsc` не пропустит перевод без ключа, тест проверяет плейсхолдеры.
